# Odd or Even 128

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Print "Even" if N is divisible by 2. Print "Odd" otherwise.

 **Input Format** 

A single integer N

 **Constraints** 

1 ≤ N ≤ 10^5

 **Output Format** 

Print "Even" if N is divisible by 2

Print "Odd" otherwise

 **Sample Input 0** 

```
4

```

 **Sample Output 0** 

```
Even

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-07T15:26:08.519Z  

```py
# Enter your code here. Read input from STDIN. Print output to STDOUT
n=int(input())
if(n%2==0):
    print("Even")
else:
    print("Odd")

```
