# Sum of 2 numbers Add

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

This is a simple exercise to get you started. Your goal is to write a program that calculates the sum of two numbers and print it.

 **Input Format** 

The input consists of a single line containing two integers, a and b, separated by a space.

 **Constraints** 

−1000≤a≤1000 −1000≤b≤1000

 **Output Format** 

Output a single integer which is the sum of a and b.

 **Sample Input 0** 

```
5 10

```

 **Sample Output 0** 

```
15

```

 **Explanation 0** 

sum of 5 and 10 is 15.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-08T13:33:22.137Z  

```py
# Enter your code here. Read input from STDIN. Print output to STDOUT
a,b=map(int,input().split())

print(a+b)

```
